# Test everything like (it was) a unit test.

Welcome to the workspace of the said titled workshop. In these documentations, you should get the gist of the workshop.

The documentation is spread using a **[Diátaxis](https://diataxis.fr)** approach for documentation. I chose this
framework because it makes it clear where certain types of documentation belongs to. And hopefully makes it clearer for
you to see what you need to do in this workshop.

In short.

- If you want to just run the second part of the training - [Read How-To](how-to/README.md)'
- if you want a reference implementation for the examples in the training, [References](./reference/README.md) is your
  place
- For Acquiring knowledge, you can read part of the [Explanation](./explanation/README.md) or go to
  the [Tutorials](./tutorial/README.md)

I hope you find this repository useful. And I'd be curious to hear any feedback - you can send them via email, or even
as Github open issues.
