# How to Test anything?

This is a copy from [Conference Examples Github repository](https://github.com/rinkkasatiainen/conference-examples),
which is used for numerous different coding exercises, all in the domain of hosting/running/attending a conference.

The 'How to Test Anything' is a workshop inspired and based on a great talk by [Sandi Metz](https://sandimetz.com/),
titled as [Magic Tricks of Testing](https://youtu.be/MT0HvF_XT08?si=JPzEEK0al4RrllxE).

Go ahead and open [The instructions of part 1](./how-to-test-anything/README.md)
